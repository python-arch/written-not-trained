=== ARCH.md (in the reader's folder) ===
# A looped network

- **Input:** a sequence of n tokens. Each token is three integers (a, b, c), with 0 ≤ a < 128, 0 ≤ b < 128 and
  0 ≤ c < 5.
- **State:** h, an n × 35 array (35 numbers per token). At the start, row i is E0[a_i] + E1[b_i] + E2[c_i].
- **One block**, applied R = 2n times with the same weights:
  - Attention, 4 heads of width 8. Head k uses columns 8k to 8k + 7 of Wq, Wk and Wv, and rows 8k to 8k + 7 of Wo.
    - Q = h Wq, K = h Wk, V = h Wv.
    - A_k = softmax over j of Q_k K_kᵀ / √8. There is no mask: every token can attend to every token. Subtract each
      row's maximum before taking exp, because scores can be very large.
    - h ← h + Σ_k A_k V_k Wo_k.
  - MLP: h ← h + relu(h W1 + b1) W2 + b2, with 86 hidden units.
  - No normalisation.
- **Output:** at every token, logits = h Wout + bout (5 numbers). The output at that token is the argmax, a symbol
  from 0 to 4.

## Files
- `weights.npz`: the arrays above (numpy), under the names used here.
- `weights.txt`: the same numbers as text, one array after another.
