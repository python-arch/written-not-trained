Run the maze network

This page runs the Maze-Hard network from the post, in your browser, on real test mazes. It loads the network's weights, … of them, and only … aren't zero. Then it runs them with one generic loop: look up each cell, run the same transformer layer again and again, and read off every cell. The loop knows nothing about mazes. The grid shows the network's own state after each loop.

Pick a maze and press Run.

What happens when you press Run

  1. Each of the 900 cells becomes one token: its row, its column, and what is there (wall, open, start or goal).
  2. In every loop, the same transformer layer runs over all the cells. Each cell reads its four neighbours. First, distance from the goal spreads out, one step per loop: the cells one step farther away learn how far they are from the goal. Once this reaches the start, the path grows from the start, one cell per loop, always to the neighbour one step closer to the goal.
  3. After every loop, the network reads off a character for every cell. The cells it marks as path are drawn in blue.
  4. When it stops, the page compares the network's grid with the dataset's answer, character by character.

The network's rule is to run 1,800 loops on a 30×30 maze. Long before that, its whole internal state stops changing: every number is the same as after the loop before. From then on, every loop gives exactly the same state, so the page stops there by default. Tick "Run all 1,800 loops" to run them anyway, which takes about a minute on a laptop.
