Run the hand-written network

This page runs the Tower of Hanoi network from the post, in your browser. It loads the network's real weights, … of them, and only … aren't zero. Then it runs them with one generic loop: look up each token, run the same transformer layer again and again, and read off the next move. The loop knows nothing about the puzzle. A separate checker on this page replays every move.

What happens when you press Run

  1. The puzzle becomes tokens: the number of disks, where each disk starts, where it should end, and a separator.
  2. For every new token, the network looks it up in its embedding table, runs the same transformer layer a few times, and reads off a score for each possible next token. The highest score is the next move.
  3. That move is added to the input, and the loop goes again, until the network writes its end token.
  4. Separately, a small checker replays each move on the pegs: the disk must be on top of its peg and may never land on a smaller one.

Each step reads every earlier token, so bigger puzzles take longer. Up to 13 disks finishes in about a second. 15 disks, 32,767 moves, takes several seconds on a laptop.
